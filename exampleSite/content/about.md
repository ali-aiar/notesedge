Hi, I'm a software engineer who writes about backend systems, embedded development, and the tools that connect them. This site is built with [NotesEdge](https://github.com/ali-aiar/notesedge), a dark Hugo theme designed for technical writers.

## What I Work On

My focus spans distributed systems, IoT platforms, and developer tooling. I enjoy taking complex infrastructure problems and breaking them down into clean, maintainable solutions. Most of my work involves Go, Python, and various cloud-native technologies.

## About This Site

NotesEdge started as a personal blog theme and evolved into a community-ready Hugo theme. It features client-side search powered by Fuse.js, a multi-column layout with category filtering, and a monospace-first design inspired by GitHub's dark mode. Every element is configurable through `config.toml` — no hardcoded values, no framework dependencies.
